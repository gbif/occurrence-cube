= Occurrence cube: Grid generator

This module generates GeoPackage files containing reference grid cells for use with
[GBIF species occurrence cubes](https://techdocs.gbif.org/en/data-use/data-cubes).

Generated grids are [available for download](https://download.gbif.org/grids/), but
alternative resolutions/sizes or more restricted areas can be generated by editing this
code.

You will need [Java](https://openjdk.org/install/) and
[Apache Maven](https://maven.apache.org/install.html) installed. (On Linux,
typically `sudo apt install maven` or `sudo yum install maven`.)

Edit the files as required, i.e. change the parameters in `DmsGridGenerator.java`,
`EeaGridGenerator.java` or `ExtendedQuarterDegreeGridGenerator.java`.

Then from the directory above this one, run

```
mvn clean package
```

And from this directory, run one or more of these commands as required

```
mvn exec:java -Dexec.mainClass=org.gbif.occurrence.cube.grids.DmsGridGenerator
mvn exec:java -Dexec.mainClass=org.gbif.occurrence.cube.grids.EeaGridGenerator
mvn exec:java -Dexec.mainClass=org.gbif.occurrence.cube.grids.ExtendedQuarterDegreeGridGenerator
```
